# Product Dashboard

This project is a dashboard application for managing seller-listed products. It allows users to update, mark as sold, and delete listed products.

## Project Structure

```
product-dashboard
├── src
│   ├── app
│   │   ├── components
│   │   │   ├── dashboard
│   │   │   ├── product-list
│   │   │   └── product-edit
│   │   ├── services
│   │   ├── models
│   │   ├── app.component.ts
│   │   ├── app.component.html
│   │   ├── app.component.scss
│   │   └── app.routes.ts
│   ├── assets
│   └── styles.scss
├── package.json
├── tsconfig.json
└── README.md
```

## Features

- **Dashboard**: Overview of products and their statuses.
- **Product List**: Displays all listed products with options to update or delete.
- **Product Edit**: Form for editing product details and marking products as sold.

## Getting Started

1. Clone the repository:
   ```
   git clone <repository-url>
   ```

2. Navigate to the project directory:
   ```
   cd product-dashboard
   ```

3. Install dependencies:
   ```
   npm install
   ```

4. Start the development server:
   ```
   ng serve
   ```

5. Open your browser and navigate to `http://localhost:4200/`.
